# 数据字典

## 1. 数据集文件格式

```json
{
  "dataset_name": "计算机类应届生招聘数据（演示样本）",
  "version": "0.1.0",
  "collected_at": "2026-11-01",
  "records": []
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| dataset_name | string | 否 | 数据集名称，仅用于导入结果回显 |
| version | string | 否 | 数据版本，建议与文件名日期对应 |
| collected_at | string (YYYY-MM-DD 或 ISO 时间戳) | 否 | 数据集采集日期；记录缺失时继承此值。时间戳按记录自身时区取日期 |
| records | array | 是 | 至少 1 条记录 |

## 2. 招聘记录字段

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | 1～64 字符，全库唯一 | 建议 `job_001` 或来源平台 id |
| company | string | 是 | 1～200 字符，非空 | 企业名称 |
| position | string | 是 | 1～200 字符，非空 | 原始岗位名称 |
| job_type | string | 否 | 默认“其他”，≤ 50 字符 | 岗位类别白名单 |
| city | string | 否 | 默认“未知”，≤ 50 字符 | 招聘城市 |
| salary_min | integer / null | 否 | ≥ 0，≤ 1,000,000 | 月薪下限（元） |
| salary_max | integer / null | 否 | ≥ 0，≤ 1,000,000，且 ≥ salary_min | 月薪上限（元） |
| education | string | 否 | 默认“不限”，≤ 30 字符 | 规范化后的学历 |
| experience | string | 否 | 默认“不限”，≤ 30 字符 | 规范化后的经验 |
| is_fresh_graduate | boolean | 否 | 默认 false | 是否明确接受应届生 |
| skills | string[] | 否 | ≤ 50 个，自动去空/去重 | 标准技能词 |
| description | string | 否 | 默认空串 | 岗位描述 |
| source | string | 否 | 默认空串，≤ 100 字符 | 来源平台/页面 |
| source_url | string | 否 | 默认空串，≤ 500 字符 | 原始链接 |
| collected_at | string (YYYY-MM-DD 或 ISO 时间戳) | 否 | 合法日期或带时区时间戳，导入时取当地日期 | 该条记录的采集日期 |

校验失败的单条记录不会阻断整份文件导入，会以 `row`、`record_id`、`message` 返回。

## 3. 规范化词表

### 3.1 学历（education）

标准值：`不限`、`大专`、`本科`、`本科及以上`、`硕士`、`硕士及以上`、`博士`、`其他`。

导入时自动映射（示例）：

| 原始写法 | 规范化 |
| --- | --- |
| 学历不限 / 不限学历 / 无要求 | 不限 |
| 专科 / 大学专科 / 大专及以上 | 大专 |
| 大学本科 / 统招本科 | 本科 |
| 本科及以上学历 / 本科以上 | 本科及以上 |
| 研究生 / 硕士研究生 | 硕士 |
| 硕士及以上 | 硕士及以上 |
| 博士研究生 | 博士 |

> 词表在 `backend/app/services/normalization.py`，可继续补充。**未收录值保留原文**，不做猜测。

### 3.2 经验（experience）

标准值：`不限`、`应届生`、`1年以内`、`1-3年`、`3-5年`、`5年以上`、`未披露`、`其他`。

| 原始写法 | 规范化 |
| --- | --- |
| 经验不限 / 无经验要求 | 不限 |
| 应届毕业生 / 应届 / 在校/应届 | 应届生 |
| 一年以内 | 1年以内 |
| 1~3年 | 1-3年 |
| 3~5年 | 3-5年 |
| 五年以上 | 5年以上 |
| 校招；明确要求最高学历毕业后无全职工作经验 | 应届生 |
| 校招；未单独披露工作年限 | 未披露 |
| 校招；原文提及工作年限或工作经历，见经验原文 | 其他 |

> **“未披露”不等于“不限”**：它只表示招聘页没有单独写出工作年限，不能据此推断企业接受无经验候选人。

### 3.3 技能（skills）

- 每项技能建议 1～20 字符，使用业界通用名称。
- 导入时 trim、去空、忽略大小写去重（保留首次出现的写法）。
- 技能分类词表：`backend/app/services/skills.py`，当前类别包括
  编程语言、开发框架、前端技术、数据库、工具与平台、人工智能、测试、计算机基础、安全、其他。
- 同义词由人工在采集阶段统一，例如：
  - `springboot` → `Spring Boot`
  - `mysql数据库` → `MySQL`
  - `java开发` → `Java`
  - `js` → `JavaScript`
- 词表未收录的技能仍会统计，只是 `category = 其他`；正式分析前应把高频“其他”补入词表。

## 4. 薪资口径

1. 所有薪资统一为**人民币月薪**，单位为元。
2. 区间型 `10000-18000` → `salary_min=10000`、`salary_max=18000`。
3. `10-18K/月` → `10000`、`18000`。
4. 年薪制：`年薪 24-36 万` → 月薪 `20000-30000`（÷12），并在采集表中保留原始文本。
5. 日薪制：按 21.75 个工作日/月换算；时薪按 174 小时/月换算。
6. `13薪/14薪`：默认按 base 月薪记录，不把年终奖摊入月薪；在数据说明页声明。
7. `面议` / 未提供：`salary_min` 与 `salary_max` 均为 `null`，**禁止填 0**。
8. 统计时使用区间中点；只有一端时取该端。

## 5. 岗位类别（job_type）

当前上海数据集沿用来源平台的 9 个类别：

`人工智能与算法`、`软件开发`、`AI基础设施与系统开发`、`数据开发与分析`、
`嵌入式与系统软件`、`软件测试与测试开发`、`运维与基础设施`、`网络安全`、`软件技术支持`。

早期文档建议的白名单（`后端开发`、`前端开发`、`算法工程` 等）不再强制；新增类别前先确认图表可读性（类别过多会让分组图难以阅读）。

## 6. 数据采集记录要求

每条记录必须能回溯：

- 来源平台与原始页面链接；
- 采集日期；
- 原始薪资文本、学历文本、经验文本（可放在采集表中，JSON 存规范化值）；
- 采集人（小组内部）。

不得采集：个人联系方式、简历、需要登录才能查看的内容、平台明确禁止采集的数据。

## 7. 数据质量检查清单

- [ ] `id` 无重复，`source_url` 抽查可访问。
- [ ] 必填字段无缺失。
- [ ] `salary_min <= salary_max`，无 0 值或异常值。
- [ ] 学历、经验落在标准词表内；未收录值有记录。
- [ ] `is_fresh_graduate` 与经验描述不矛盾。
- [ ] 技能已去重，未混入整句描述。
- [ ] JSON 文件可通过 `python -m scripts.import_sample <file>` 导入。
- [ ] 样本量、采集城市、采集时间写入 `docs/architecture.md` 或 README。

## 8. 当前数据集

### 8.1 上海真实数据

`backend/data/raw/shanghai_graduate_jobs_2026-11-13.json`：

- 280 条去重后的公开校招岗位记录，城市均为上海，采集日期 2026-11-13；
- 来源：牛客网校园招聘（`https://www.nowcoder.com/jobs/school/jobs`），逐条保留 `source_url`；
- 岗位类别 9 类，覆盖 65 家企业；全部标记为接受应届生；
- 薪资：134 条有明确月薪区间，146 条为“面议”（47.9% 薪资缺失）；
- 技能：54 条岗位的技能数超过 10 项（最多 24 项），10 条为空；导入时保留全部技能，不做截断；
- 经验：20 条明确“最高学历毕业后无全职工作经验”，256 条未披露年限，4 条原文提及工作经历或年限；
- 离线检查 280 条全部可导入；独立核对 825/825 项与 API 一致；
- 该批次是阶段性样本，后续还会合并其他数据，页面结论只适用于当前样本。

### 8.2 演示数据

`backend/data/raw/sample_jobs.json`：

- 10 条记录，企业名带「（虚构）」，链接指向 `example.com`；
- **不得用于新闻结论**，仅验证导入、查询、统计与前端联通。
